FULL DESCRIPTION (max 4000 characters):
--------------------------------------------
Matrix Clock is the companion app to control your ESP32-based 64x64 LED matrix.

🎮 MAIN FEATURES

• Bluetooth connection - Finds your display nearby and pairs with a PIN shown on the matrix; the clock syncs with your phone every time you connect
• Clock control - Sync time, set manually or use the DS3231 RTC module
• 14+ visual effects - Scroll Text, Plasma, Pong, Matrix Rain, Fire, Starfield and more
• Smart brightness - Automatic day/night adjustment with customizable schedules
• Firmware updates over Bluetooth - No need to join the display's WiFi network
• Debug console - Real-time monitoring of device communication

⚙️ AVAILABLE CONTROLS

• Play/Pause/Next - Control effect playback
• Effect selection - Choose from 14+ different animations
• Time sync - Sync with phone or set manually
• RTC/Fake mode - Use hardware clock or simulate time
• Day/Night brightness - Separate sliders for each mode
• Night schedule - Set when to activate night mode

📡 CONNECTIVITY

The app connects to your ESP32 device via Bluetooth Low Energy (firmware 3.x). Devices with the previous firmware are still supported over local WiFi (WebSocket).

🔧 REQUIREMENTS

• 64x64 LED matrix with ESP32 controller
• Compatible firmware installed on device
• Bluetooth enabled on your phone (or the same WiFi network for devices with the previous firmware)

💡 PERFECT FOR

• Maker and DIY projects
• Custom desk clocks
• Decorative displays
• LED art installations

The app is completely free and ad-free.
